Acute Web 2.0 Beta 2: private by default

By Iian Kehn

Acute Web 2.0 Beta 2 makes privacy protections the starting point and fixes the main-menu crash reported in Beta 1.

Protection from the first launch

Strict tracking protection, HTTPS-Only mode, and Global Privacy Control are enabled by default. New installations explain this during first run; upgrades from Beta 1 show a one-time notice while preserving settings you have already changed. Privacy and security settings summarize the defaults.

If a site breaks, the address-bar shield lets you turn protection off for that site. Home-network devices reached by private IP addresses open normally. Local host names such as nas.lan can show an HTTPS-Only notice with an option to continue over HTTP.

A working menu and clearer settings

Beta 2 fixes the crash when opening the main menu on a web page. Settings are grouped into focused categories, including Appearance, Privacy and security, Downloads and links, and Extensions.

The welcome page uses Acute’s own artwork and states the project’s open-source licensing and absence of telemetry, diagnostics, and crash reports. Repeated prompts to set the default browser, sign in to sync, or try a VPN are disabled.

Still a beta

This is a prerelease, not the stable 2.0 launch. The published notes also identify a remaining limitation: HTTP exceptions for local host names last only until Acute closes. The stable 1.1 release remains separate.
