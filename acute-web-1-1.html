Acute Web 1.1: room to do more

By Iian Kehn

Acute Web 1.1 expands the browser’s larger-screen experience and adds native x86_64 builds alongside ARM64.

A toolbar that stays within reach

On larger screens, the browser controls stay visible instead of following the phone’s auto-hide behavior. The release also refines CORE Glass depth and the toolbar treatment for those layouts.

Keyboard and mouse controls

Desktop keyboard controls cover focusing the address bar, opening and closing tabs, switching tabs, reopening a closed tab, refreshing, and navigating. Mouse back and forward buttons are supported too.

Two architectures, the right update

The release includes separate ARM64 and x86_64 APKs. The updater selects the package for the device’s architecture, and the build process verifies the architecture of Gecko’s native libraries.

Android 12 remains the minimum supported version. Telemetry and diagnostic uploads remain disabled. The release includes signed APKs, checksums, signing and permissions reports, build-input records, and provenance.

Compatibility note

An immediate startup crash has been reported under Waydroid on Fedora with x86_64. That issue is under investigation; native x86_64 availability does not mean that environment has been confirmed working.
