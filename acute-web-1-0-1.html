Acute Web 1.0.1: two focused fixes

By Iian Kehn

Acute Web 1.0.1 addresses two issues that surfaced around the 1.0 release: missed updates and incorrect web app sizing with CORE Glass.

Retrying an incomplete release

A GitHub release can become visible before its trusted APK is attached. The updater now treats that as an incomplete check and retries after 15 minutes, instead of recording a successful check and missing the update.

Giving web apps the right viewport

The release corrects CORE Glass viewport sizing for sites that use fixed or dynamic-height layouts, including ChatGPT.

This release is for ARM64 devices running Android 12 or newer. The APK is signed and provenance-attested.
