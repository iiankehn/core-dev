Acute Web 0.5 beta comes to iPhone and iPad

By Iian Kehn

Acute Web 0.5 is a published beta for iPhone and iPad, available through self-signed sideloading—not the App Store or TestFlight.

Layouts that follow the window

The beta adapts navigation to the available window space, including sidebar access to bookmarks, history, and downloads on iPad and an open iPhone Duo. Fold-aware layouts move controls away from the fold or separate the page from the controls. Those Duo layouts have only been tested in the simulator.

More everyday browsing tools

Back and forward history menus, pull to refresh, bookmark and history address suggestions, bookmark folders, HTML bookmark import and export, and editable favorites are included. iPad also supports multiple windows. Downloads ask first for the visible tab and provide progress, retry, and resume controls.

Private browsing and site controls

The app-switcher cover hides the screen whenever a private tab is open. Private tabs share a temporary data store that ends when the last private tab closes. Plain HTTP pages show “Not Secure,” website dialogs can be limited or blocked, and camera and microphone permissions can be reviewed per site. The app collects no telemetry or analytics.

Beta limits matter

The release reports automated tests on iOS 27.0 and 27.1 simulators, including light- and dark-mode accessibility audits. Full physical-device testing is not complete. The minimum is iOS or iPadOS 18, but versions 18 through 26 have not been tested. Acute cannot currently be set as the default browser, and downloads may stop when iOS suspends the app.

Getting the beta

The release provides an unsigned IPA and checksum file. You must sign and install it yourself; the release notes explain the tooling, requirements, and free-account limits. This is a testing release, not a claim of stable-release parity with Android.
