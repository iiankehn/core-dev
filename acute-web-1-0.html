Acute Web reaches 1.0

By Iian Kehn

Acute Web 1.0 is the browser’s first production release.

The release brings the CORE Glass and Midnight interface to ARM64 Android phones and tablets. Telemetry and crash reporting are disabled.

A verifiable release

Updates use a signed GitHub release path. Alongside the APK, the release workflow publishes a checksum, signing report, permissions report, build inputs, and provenance attestation.

Subsequent releases address update detection and viewport sizing, and add native x86_64 builds and larger-screen controls. The 1.0 release remains part of the project’s history.
