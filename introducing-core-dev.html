Introducing CORE Dev

By Iian Kehn

CORE Dev is the home for updates to the apps and websites I’m building.

Acute Web, Slate, CORE, and my personal website each have their own purpose. This blog brings their release notes and development updates together, so you can see what changed without following every repository.

What you’ll find here

Release posts will explain the changes that affect everyday use, link to the published release, and call out relevant compatibility details. Development posts will cover improvements as they take shape, with a clear distinction between work in progress and software you can download.

The first entries look back at Acute Web’s recent releases: larger-screen controls in 1.1, and update detection and CORE Glass fixes in 1.0.1.

— Iian
